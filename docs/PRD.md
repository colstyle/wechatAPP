## 一、产品概述

### 1.1 背景与目标

「小时光租衣舍」是一款面向青岛地区的线下自助租衣微信小程序，定位为**单人高性价比穿搭体验**。用户在线选定租赁日期与服装，到店自助扫码取衣，归还后由店主审核并退押金。

**核心价值主张**：
- 省钱：3件69.9元，享受高品位穿搭
- 省心：24小时自助，无需营业时间限制
- 高效：日期预锁，取衣即走，无排队

### 1.2 用户群体

| 用户类型 | 描述 | 核心诉求 |
|---|---|---|
| **普通用户（C端）** | 需要租衣的消费者，25-40岁女性为主 | 快速找到合适服装并完成下单 |
| **店主/管理员（B端）** | 门店运营者 | 高效管理订单、押金结算、服装库存 |

---

## 二、角色与权限（RBAC）

| 角色 | 标识 | 权限范围 |
|---|---|---|
| **普通用户** | `role=1` 或 `role=user` | 选日期、浏览服装、下单（单品/套餐）、支付、取衣、还衣、AI咨询、查看个人订单 |
| **店主/管理员** | `role=2` 或 `role=admin` | 普通用户所有权限 + 全量订单管理、退押金、扣费、换款、套餐配置、**服装库存管理（新增/编辑/删除商品）** |

> **分流规则**：登录成功后，后端返回 `role` 字段，前端 `app.js` 自动判断：若为 admin，则跳转至店主端首页。

## 三、功能需求

### 3.1 用户端功能

#### F01 — 微信授权登录

- **触发**：用户打开小程序时自动触发
- **流程**：小程序调用 `wx.login()` 获取 code → 发送至后端 → 后端调用微信 jscode2session 换取 openid → 查询/创建用户 → 返回 JWT token
- **优先级**：🔴 P0（核心，其他功能依赖）
- **验收标准**：
  - 新用户首次进入自动完成静默登录，无需手动操作
  - 同一微信账号多次登录，openid 保持不变
  - token 过期后自动刷新，用户无感知

#### F02 — 日期选择（租赁日期锁定）

- **触发**：进入首页
- **流程**：弹出全屏日历 → 用户选定日期 → 日期存储至全局 `globalData.selectedDate`
- **规则**：
  - 只能选今日或今日之后的日期
  - 未选日期前，商品列表不显示（显示引导占位）
  - 同一日期内，已被预约的衣物不出现在列表中
- **优先级**：🔴 P0
- **验收标准**：
  - 日历展示当月及下月可选日期
  - 手动预订数据库某衣物→刷新→该衣物消失，验证日期联动

#### F03 — 商品浏览与搜索

- **功能点**：
  - 按分类筛选（大衣/连衣裙/裤装等）
  - 搜索框：关键词模糊匹配
  - 商品卡片：图片（3:4比例）、名称、租金、押金
  - 已选日期对应的可租状态实时展示
- **优先级**：🔴 P0

#### F04 — 商品详情

- **功能点**：
  - 服装主图（可滑动多图）
  - 服装信息：品牌、尺码、颜色、日租金、押金
  - "立即预定"按钮（单品）
  - 是否参与套餐标识
  - 进入 AI 客服入口
- **优先级**：🔴 P0

#### F05 — 下单：单品租赁

- **流程**：商品详情 → 「立即预定」→ 确认订单页（已选日期/衣物/金额）→ 提交订单 → 进入支付
- **金额规则**：租金（单价）+ 押金
- **优先级**：🔴 P0

#### F06 — 下单：3件69.9套餐

- **流程**：分类页 → 批量选衣（最多3件）→ 已选计数实时显示 → 「去下单」→ 确认订单页 → 提交
- **金额规则**：租金固定 69.9 元 + 每件衣物押金之和
- **规则**：
  - 选满3件才能提交（少于3件按钮禁用）
  - 选到第4件时弹出提示"套餐仅限3件，请先取消一件"
  - 只有标记为 `is_package_eligible=true` 的衣物可以参与套餐
- **优先级**：🔴 P0

#### F07 — 支付

- **当前阶段**：模拟支付（点击后直接跳转支付成功）
- **后续阶段**：接入微信支付 V3 真实环境
- **支付项**：租金 + 押金（合并一笔）
- **优先级**：🟡 P1（当前模拟，上线前切换真实）

#### F08 — 订单管理（用户端）

- **列表**：我的订单列表，支持状态筛选（待支付/待取衣/租赁中/待审核/已完成）
- **详情**：
  - 订单号、服装信息、日期、金额明细
  - 状态为"待取衣"时：显示取衣码/门锁密码
  - 状态为"租赁中"时：显示24小时环形倒计时
  - "我已取衣"按钮（激活计时）
  - "我已还衣"按钮（申请归还）
- **优先级**：🔴 P0

#### F09 — 24小时租赁计时

- **规则**：
  - 用户点击"我已取衣"时，服务端记录 `pickup_time`，计算 `expected_return_time = pickup_time + 24h`
  - 前端每秒刷新显示剩余时长（环形可视化仪表盘）
  - 逾期时长由服务端在还衣时计算
- **优先级**：🔴 P0

#### F10 — AI 智能客服

- **功能**：全屏对话界面，支持多轮对话
- **能力**：
  - 解答业务问题（套餐价格、取衣流程、逾期规则等）
  - 穿搭灵感建议
  - 基于业务文档的 System Prompt 驱动
- **AI 引擎**：DeepSeek-V3（默认）/ Google Gemini（可切换）
- **优先级**：🟡 P1

#### F11 — 个人中心

- **功能点**：
  - 展示头像/昵称（微信授权信息）
  - 快捷入口：我的订单、AI客服
  - 开发者设置入口（dev环境显示）：配置 apiBase、mock openid
  - 店主身份时展示"店铺管理"入口
- **优先级**：🔴 P0

### 3.2 店主端功能

#### F20 — 店主端首页（订单列表）

- **功能点**：
  - 全量订单列表（所有用户）
  - 状态筛选 Tab（全部/待取衣/租赁中/待审核/已完成）
  - 关键词搜索（订单号后4位/用户昵称）
  - 每条订单显示：用户昵称、衣物信息、日期、当前状态
- **优先级**：🔴 P0

#### F21 — 订单详情管理

- **操作**：
  - **退押金**：针对"待审核"状态，一键全额退押，订单变为"已完成"
  - **手动扣费**：输入扣费金额和原因（逾期/损毁），最终退款 = 押金 - 扣费额
  - **换款**：修改"待取衣"状态订单的衣物，押金随之更新
  - 所有操作均记录操作备注，可在详情中查看
- **优先级**：🔴 P0

#### F22 -- 套餐商品配置

- **功能**：店主可设置哪些衣物参与3件69.9套餐
- **操作**：在商品列表中切换 `is_package_eligible` 开关
- **优先级**：🟡 P1

#### F23 -- 服装库存管理

- **入口**：店主端 → 「库存管理」Tab
- **功能点**：
  - **商品列表**：展示全部服装，含缩略图、名称、当日状态（空闲 / 出租中 / 已下架）
  - **新增商品**：表单填写以下字段后上架：
    - 基本信息：名称、品牌、分类、颜色、尺码、描述
    - 定价：日租金（元）、押金（元）
    - 图片：最多上传 5 张（`wx.chooseMedia` + 图片上传接口）
    - 套餐资格：是否参与3件69.9套餐（`is_package_eligible`）
  - **编辑商品**：修改上述任意字段，修改后前台立即生效
  - **下架商品**（软删除）：商品从用户端隐藏，已有关联订单不受影响
  - **删除商品**（硬删除）：仅允许对「无任何订单关联」的商品执行；有历史订单则只能下架，删除按钮置灰
  - 删除操作须二次确认弹窗
- **优先级**：🟡 P1
- **验收标准**：
  - 新增商品后，前台商品列表立即可见（对应日期空闲时）
  - 有订单关联的商品，删除按钮置灰并提示「请先完成关联订单」
  - 图片上传失败时给出明确错误提示
  - 商品信息被修改后，进行中订单的商品快照不受影响（快照在下单时已固化）
- **涉及后端接口**（`product.py` 需新增或补全，仅限 admin 调用）：

  | 方法 | 路径 | 说明 |
  |---|---|---|
  | POST | `/api/v1/product/products` | 新增商品 |
  | PUT | `/api/v1/product/products/{id}` | 编辑商品 |
  | DELETE | `/api/v1/product/products/{id}` | 删除/下架商品 |
  | POST | `/api/v1/upload/image` | 图片上传（已有框架） |

## 四、非功能性需求

### 4.1 性能

| 指标 | 要求 |
|---|---|
| 首页加载时间 | ≤ 2s（4G 网络） |
| 商品列表滚动帧率 | ≥ 60fps |
| API 响应时间 | ≤ 500ms（P90） |
| 并发下单防超卖 | 同一件衣物同一日期，数据库事务保证原子性 |

### 4.2 安全

| 要求 | 说明 |
|---|---|
| 所有接口鉴权 | 除登录接口外，均需携带有效 JWT Bearer Token |
| 管理员接口双重校验 | 前端权限拦截 + 后端 role 字段校验 |
| 微信 jscode2session | 上线前必须调用真实微信接口获取 openid |
| HTTPS | 生产环境强制 HTTPS，小程序合规要求 |
| 密钥安全 | JWT_SECRET_KEY 等敏感配置不出现在代码仓库 |

### 4.3 兼容性

- iOS 微信 ≥ 8.0
- Android 微信 ≥ 8.0
- 小程序基础库 ≥ 3.0

### 4.4 视觉规范（设计约束）

详见 `docs/DESIGN.md`。

## 五、业务术语表

| 术语 | 定义 |
|---|---|
| 租金 | 借用服装的费用，套餐固定69.9元 |
| 押金 | 每件衣物的保证金，归还审核通过后退还 |
| 逾期费 | 超过24小时未还衣产生的额外费用（由店主人工扣除） |
| 套餐 | 3件69.9元优惠组合，仅限参与套餐的衣物 |
| 取衣码/门锁密码 | 用户到店自助取衣所需的临时密码（TTLock对接后自动生成） |
